# Data

How to handle information.

- [DT-1](../sources/data-classification.md#dt-1): All data has one of four classes: Public, Internal, Confidential and Restricted.
- [DT-2](../sources/data-classification.md#dt-2): [PII](glossary.md#pii) is classed Confidential at minimum.
- [DT-3](../sources/data-classification.md#dt-3): Store Restricted data only in the approved vault, never in chat or email.
- [DT-4](../sources/data-classification.md#dt-4): Customer data is deleted 30 days after the customer's contract ends.
